1. Обзор проекта

Mangystau Jobs — это полноценная веб-платформа для поиска работы и найма сотрудников, созданная специально для решения проблемы неоцифрованного рынка труда в Мангистауской области.

🎯 Проблема

Вакансии живут в WhatsApp-чатах, hh.ru не охватывает малый бизнес Актау, молодёжь не видит возможностей рядом.

✅ Решение

Единая платформа с AI-подбором, фильтрацией по микрорайонам и Telegram-уведомлениями.

Хакатон Mangystau Hackathon 2025 - Решение для 1 места

6. API эндпоинты

GET /api_get_jobs.php

Получение списка вакансий с фильтрацией

Параметры:
- title (string) - поиск по названию/описанию
- district (string) - фильтр по микрорайону
- type (string) - фильтр по типу занятости

Ответ: JSON массив объектов вакансий

POST /api_apply.php

Создание отклика на вакансию

Параметры:
- job_id (int) - ID вакансии

Ответ: {"success": true, "ai_score": 94}

GET /api_ai_match.php

Получение AI-рекомендаций для соискателя

Ответ: JSON массив вакансий с процентом совпадения

POST /api_create_job.php

Создание новой вакансии (только employer)

Параметры: title, description, skills, salary_min, salary_max, district, type

Ответ: {"success": true}

GET /api_get_my_jobs.php

Получение вакансий работодателя

Ответ: JSON массив вакансий с количеством откликов

GET /api_get_responses.php

Получение откликов на вакансии работодателя

Ответ: JSON массив откликов с данными соискателей

POST /api_update_status.php

Обновление статуса отклика

Параметры: app_id (int), status (pending/accepted/rejected)

Ответ: {"success": true}

7. AI алгоритм матчинга

Формула расчёта совпадения

Match Score = (Skills Match × 60%) + (Location Match × 30%) + (Experience Match × 10%)
Навыки (60%)

Сравнение навыков соискателя с требованиями вакансии через пересечение множеств

Локация (30%)

Совпадение микрорайона даёт +30 баллов, в противном случае +10

Опыт (10%)

Чем ближе опыт к требованию, тем выше балл (макс 10)

Пример работы AI

Соискатель: Навыки: "бариста, кассир, английский" | Микрорайон: 3 | Опыт: 2 года
Вакансия:   Навыки: "бариста, кофемашина" | Микрорайон: 3 | Требование опыта: 1+ год

Расчёт:
- Навыки: общие: ["бариста"] → 1/2 × 60 = 30 баллов
- Локация: совпадает → 30 баллов
- Опыт: 2 года ≥ 1 года → 10 баллов
ИТОГО: 70% совпадения

8. Установка и настройка

Шаг 1: Установка локального сервера

  • Скачайте и установите XAMPP или WAMP
  • Запустите Apache и MySQL серверы
  • Убедитесь, что порты 80 и 3306 свободны

Шаг 2: Размещение файлов

  • Скопируйте все файлы в папку: C:\xampp\htdocs\mangystau_hackathon\ (для XAMPP)
  • Убедитесь, что структура папок сохранена

Шаг 3: Настройка базы данных

  • Откройте phpMyAdmin: http://localhost/phpmyadmin
  • Создайте базу данных: mangystau_jobs
  • Импортируйте файл database.sql
  • Проверьте подключение в database.php

Шаг 4: Запуск приложения

  • Откройте браузер
  • Перейдите по адресу: http://localhost/mangystau_hackathon/index.html
  • Готово! Платформа запущена

9. Деплой на хостинг

🚀 Railway.app

  1. Создайте аккаунт на railway.app
  2. Подключите GitHub репозиторий
  3. Добавьте MySQL базу данных
  4. Настройте переменные окружения
  5. Деплой автоматический

🚀 Render.com

  1. Создайте аккаунт на render.com
  2. Выберите "New Web Service"
  3. Подключите GitHub репозиторий
  4. Выберите "PHP Runtime"
  5. Нажмите "Deploy"

Важно: Не забудьте изменить настройки базы данных в database.php после деплоя!

11. Решение проблем

❌ Ошибка: "Connection failed"

Решение: Проверьте настройки в database.php (хост, пользователь, пароль, имя БД)

❌ Ошибка: "404 Not Found"

Решение: Убедитесь, что все файлы скопированы в правильную папку и пути указаны верно

❌ Ошибка: "Session start failed"

Решение: Проверьте, что нет пробелов или вывода до session_start() в PHP файлах

❌ Не показываются AI рекомендации

Решение: Убедитесь, что у соискателя заполнены навыки, микрорайон и опыт в профиле

12. Безопасность

Хеширование паролей

Пароли хранятся в БД с использованием password_hash() и password_verify()

Защита от SQL-инъекций

Используются подготовленные запросы PDO

XSS защита

Все выводы экранируются через htmlspecialchars()

Сессии

Проверка авторизации перед доступом к защищённым страницам
